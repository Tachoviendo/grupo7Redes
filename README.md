## Objetivo

![Objetivo](https://img.shields.io/badge/-Objetivo-2c3e50?style=flat-square)

Familiarizarse con conceptos básicos sobre redes, Internet y utilizar herramientas para diagnóstico, debug y análisis de tráfico de red.

---

## Entorno de trabajo

![Entorno](https://img.shields.io/badge/-Entorno%20de%20trabajo-2c3e50?style=flat-square)

Se recomienda realizar las pruebas en una máquina virtual con Linux. En las imágenes de Kali Linux, las herramientas tcpdump, Wireshark y tshark vienen instaladas por defecto.
